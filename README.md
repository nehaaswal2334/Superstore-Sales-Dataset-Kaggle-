# Superstore-Sales-Dataset-Kaggle-



Minor Project: Sales Data Analysis & Business Insights Dashboard

Project Overview

This project is part of the Data Science internship at Skillairo Edutech. The objective is to analyze historical sales data to uncover trends, identify seasonality, and highlight performance gaps across various regions and product categories. By cleaning and visualizing transactional data, this project aims to provide actionable business insights to stakeholders.

Dataset

Source: Superstore Sales Dataset (Kaggle)

Description: Contains transactional data for a retail superstore, including order dates, regions, product categories, and sales figures.

Tools & Technologies Used

Language: Python

Libraries: Pandas, Matplotlib, Seaborn

Techniques: Exploratory Data Analysis (EDA), Data Cleaning, Time-Series Exploration, Business Analytics

Project Workflow

Data Preprocessing: Cleaned the dataset by handling missing values, standardizing formats, and extracting date features.

Trend Analysis: Evaluated sales trends over time to identify peak seasons and potential drops in revenue.

Performance Metrics: Grouped data to identify top-performing products, categories, and geographic regions.

Data Visualization: Created a comprehensive visual dashboard using Matplotlib and Seaborn to communicate findings to non-technical stakeholders.
